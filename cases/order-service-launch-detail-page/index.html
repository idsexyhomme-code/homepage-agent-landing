상세페이지·인쇄물

주문 정리 서비스 런칭 콘텐츠

산지로 · 택배 주문 자동 정리 서비스 · 펀딩 · B2B

2026년 10월

과제

기능은 많았지만 기능 목록만으로는 '내 일이 어떻게 줄어드는지'가 전해지지 않았습니다.

한 일

손 입력과 서비스 정리를 직접 녹화해 비교하고, 고객군별 말투로 기능을 '바뀌는 하루'로 풀었습니다.

결과물

펀딩 상세페이지 15개 섹션 · 실사용 녹화 비교 페이지 · 택배 대리점 도입 제안서 11쪽

문제

기능은 많았지만, 기능 목록만으로는 「내 일이 어떻게 줄어드는지」가 전해지지 않았습니다.

고객 분석

농장주 · 동대문 사입 · 택배 대리점 세 고객군의 실제 말투를 모아 불편을 정리하고, 기능마다 「그래서 내 하루가 어떻게 바뀌는지」로 번역하는 구조를 잡았습니다.

증거 설계

같은 명단 다섯 줄을 손으로 입력할 때와 서비스로 정리할 때를 각각 녹화해 비교 페이지를 만들었습니다. 붙여넣기 → 확인 → 엑셀 받기 3단계 사용 흐름과 실제 화면, 현장 사용 기록, 송장 출력까지 이어지는 출고 흐름, 자주 묻는 질문을 세로형 상세페이지로 배치했습니다. 화면 속 이름 · 번호는 모두 예시용 가상 데이터입니다.

B2B 제안

택배 대리점을 위해 현황 분석 → 제안 → 기능 상세 → 정확도 · 개인정보 보호 → 추진 일정 순서의 도입 제안서를 따로 작성했습니다.

운영

상세페이지는 편집 가능한 디자인 파일로 넘겨, 펀딩 오픈 전 수정에 바로 대응할 수 있게 했습니다.

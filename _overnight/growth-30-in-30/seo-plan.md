# 검색 SEO 계획 — "제주 [업종] 홍보영상" 유입

> 느리지만 누적 채널. 목표: 검색 유입 → `/free` 무료오퍼 → 문의. 4주에 5건.

## 1. 이미 된 것(강점)
- 4개국어 · 구조화데이터(Org·Service·FAQ·VideoObject·Breadcrumb) · sitemap · hreflang · 타이틀 키워드 최적화.
- 서비스 상세 8p는 각각 "제주 드론촬영/AI 숏폼/기업영상" 등 키워드 보유.
- **즉시 할 것**: 구글서치콘솔·네이버서치어드바이저에 `/free` + 사이트맵 재제출(색인 요청).

## 2. 신규 업종별 랜딩(고전환 롱테일) — 빌드 대기
각 페이지 = 그 업종 검색자에게 딱 맞는 카피 + 관련 작업 + `/free` 오퍼. (freePage/detailPage 패턴 재사용, 라우트+셸+sitemap)

| URL(안) | 타깃 검색어 | 히어로 h1 |
|---|---|---|
| `/jeju-food-video` | 제주 음식점 홍보영상·맛집 릴스 | 제주 맛집 사장님, 손님이 오고 싶게 만드는 30초 |
| `/jeju-pension-video` | 제주 펜션/숙소 홍보영상·드론 | 제주 펜션, 예약을 부르는 영상·드론컷 |
| `/jeju-cafe-reels` | 제주 카페 릴스·감성 영상 | 제주 카페, 감성이 도는 릴스 한 편 |
| `/jeju-farm-video` | 제주 농장/체험 홍보영상 | 제주 농장·체험, 신뢰를 주는 소개 영상 |

- 공통 구조: 라이트 히어로(업종 특화 h1+lead) → 왜 필요한지(3) → 관련 작업 릴 → **무료오퍼 배너** → 문의폼.
- 각 셸: title/desc에 업종 검색어, WebPage JSON-LD.
- sitemap 4개 추가.

## 3. 콘텐츠(블로그성, 선택)
- "제주 음식점 홍보영상 비용/방법" 같은 정보성 1~2편(네이버 블로그 또는 사이트) → 검색 유입.

## 4. 측정
- 서치콘솔 노출·클릭 주간 체크. 유입 검색어 확인 → 랜딩 카피 보강.
- 유입 후 문의는 `utm_source=naver/google`로 귀속.

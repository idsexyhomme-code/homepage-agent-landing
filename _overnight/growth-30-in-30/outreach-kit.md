# 아웃리치 키트 — 복붙 실행용 (제주 사장님 타깃)

> 핵심 훅: **"무료로 샘플 컷 3장 만들어 드려요"** — 사진만 받으면 됨.
> 하루 5~10곳 접촉 = 주 25~50곳 → 응답 10~20% → 주 3~8 리드.

---

## A. 타깃 어디서 찾나 (하루 10곳, 15분)
1. **인스타 해시태그**: `#제주맛집` `#제주펜션` `#제주카페` `#제주농장` `#제주소품샵` `#애월카페` `#서귀포맛집` → 게시물 활발한데 **영상이 없거나 사진만 있는** 계정.
2. **네이버플레이스**: "제주 [지역] 맛집/펜션/카페" → 리뷰 많은데 **대표사진 허접/영상 없는** 곳.
3. **당근 비즈니스**: 제주 동네 업체.
4. **우선순위**: ①신규 오픈(홍보 절박) ②사진은 예쁜데 영상 없음 ③객단가 높음(펜션·오마카세·체험) → 유료 전환 큼.

## B. 인스타 DM 템플릿 (가장 반응 좋음)
> 상대 게시물 1개를 진짜로 보고 첫 줄에 언급 = 스팸 아님 신호.

```
안녕하세요 사장님! [게시물/메뉴 구체 언급 — 예: 흑돼지 플레이팅]이 너무 좋아서 메시지 드려요 :)
제주에서 영상 만드는 '비디오 로스터리'예요.

요즘 릴스·숏폼 하나 있으면 노출이 확 달라지는데,
사장님 가게는 사진이 이미 예뻐서 영상으로 만들면 정말 잘 나올 것 같아요.

그래서 제안 하나 — 가게/제품 사진 몇 장만 보내주시면
촬영 없이 **무료로 샘플 컷 3장**(영상에 그대로 들어갈 정지컷)을 만들어서 보여드릴게요.
마음에 드시면 그때 정식으로 진행하시면 되고, 아니면 편하게 안 하셔도 돼요.

관심 있으시면 "네" 한 마디만 남겨주세요! (이번 달 선착순 몇 팀만 도와드려요)
— 비디오 로스터리 · videoroastery.com · 40+ 실제 제작 영상
```

## D. 크몽 기그 최적화 (무료샘플 훅 이식)
- **기그 제목 앞**에: `[무료 샘플] ` 또는 `사진만 주세요 · ` 붙이기.
  - 예: `사진만 주세요 · AI로 제품 홍보 숏폼 만들어 드립니다`
- **상세 최상단 3줄**:
  ```
  ✅ 구매 전, 사진 몇 장 주시면 무료 샘플 컷 3장 먼저 보여드립니다.
  ✅ 촬영 없이 보유 사진만으로 제작 (제주 현장 촬영도 가능)
  ✅ 크몽 24건+ 완료 · 40+ 실제 제작 영상
  ```
- **패키지 최저가 티어 신설**: "테스트 1편" 저가 진입 → 재구매/업셀.
- **응답 속도**: 크몽은 응답률·응답속도가 노출에 직결. 1시간 내 응답 유지.

## E. 실행 리듬 (하루 20분)
- 아침: 타깃 10곳 찾기(15분) → DM/메일 발송.
- 점심/저녁: 크몽·인스타 문의 응답(1시간 내).
- 리드 오면: 사진 받고 → 무료 샘플 제작 → "정식은 이렇게 됩니다" 견적.
- **모든 리드는 아래 시트에 기록**(채널·날짜·상태) → 30건 카운트.

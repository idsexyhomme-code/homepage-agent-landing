# 30 real inquiries in 30 days — Video Roastery 성장 플랜

> 목표(대표 확정): **한 달간 진짜 문의/리드 30건** · 채널 = 직접 아웃리치 + 검색 SEO(네이버/구글) + 인스타/당근 + 크몽 전부
> 제약: **배포는 당장 안 함(전부 스테이징)** · 밤새 루프로 빌드업

---

## 0. 전략 한 줄
**모든 채널을 하나의 "무료 30초 홍보영상 샘플" 오퍼로 모아, 문의(=리드)로 전환한다.**
- 왜 이게 키스톤인가: (1) VR의 **AI 숏폼**은 촬영 없이 사진만으로 제작 → 무료 샘플 원가 낮음 (2) 사장님이 **자기 가게가 영상이 된 걸 눈으로 봄** → 유료 전환률 급등 (3) 진입 마찰 최소(사진만 보내면 됨) (4) **모든 채널(크몽·인스타·당근·SEO·아웃리치)이 이 한 오퍼로 수렴** → 메시지 일관 + 측정 가능.
- 리드의 정의 = **무료 샘플 신청/문의** 1건. 대표가 자격 판단 후 샘플 제공 → 유료 제안.

## 1. 퍼널 & 숫자
```
채널 트래픽  →  무료샘플 랜딩(/free)  →  문의(리드)  →  샘플 제공  →  유료 전환
```
- 30 리드/30일 = **하루 1건**. 채널 분산 목표(현실적 배분):
  | 채널 | 30일 리드 목표 | 근거 |
  |---|---|---|
  | 크몽 | 8 | 이미 ★4.5 실거래, 최적화+무료샘플 훅 |
  | 직접 아웃리치 | 8 | 최고 전환, 대표가 하루 5~10곳 DM/메일 |
  | 인스타/당근 | 7 | 릴스·비포애프터 + 지역 |
  | 검색 SEO | 5 | "제주 [업종] 홍보영상" 유입(느리지만 누적) |
  | 소개/재구매 | 2 | 기존 크몽 고객 |
- 전환 가정: 랜딩 방문→문의 5~8%(무료 오퍼라 높음). 즉 하루 방문 ~15~20이면 1건.

## 2. 오퍼 설계 (핵심)
**"제주 사장님, 무료로 30초 홍보영상 만들어 드립니다"**
- 받는 것: 업종 + 제품/공간 사진 몇 장 + 연락처
- 주는 것: 30초 세로 숏폼 샘플 1편(AI, 촬영無)
- 볼륨 관리: "**이번 달 선착순 N팀**" 문구로 희소성 + 대표 소화량 조절
- 유료 전환 경로: 샘플 만족 → 정식 편수/버전/채널별 리사이즈 패키지 견적

## 3. 내가 빌드하는 것 (스테이징, 미배포)
1. **무료샘플 랜딩 `/free`** — BASIC 스타일, 고전환(히어로+작동방식 3단계+실제 사례 릴+초간단 폼). 모든 채널의 착지점.
2. **사이트 전역 진입 배너/CTA** — 홈·상세에서 무료 오퍼로 유도.
3. **채널별 UTM 트래킹** — 문의 mailto/폼에 `utm_source`별 태깅 → 30건이 어디서 왔는지 측정. (기존 trackingSummary 활용)
4. **아웃리치 키트**(docs, 대표 실행용): 크몽 기그 카피 · 인스타 30일 콘텐츠 캘린더 · 당근/네이버플레이스 세팅 가이드 · DM/메일 템플릿 · 제주 타깃 접근법.
5. **측정 대시보드 가이드** — 30건 카운트 방법(UTM별 · 주차별 목표 대비).

## 4. 30일 주차 목표
- **W1(세팅+5)**: 랜딩·배너·트래킹 배포(대표 승인 후) · 크몽 기그 무료샘플 훅 · 인스타 프로필/하이라이트 정비 · 아웃리치 리스트 30곳 작성 → 첫 5건.
- **W2(8)**: 인스타 데일리 릴스 시작 · 아웃리치 하루 5곳 · 당근 비즈프로필.
- **W3(8)**: SEO 랜딩 유입 시작 · 후기 요청(전환 고객) · 리타깃.
- **W4(9)**: 마감 스퍼트 · 선착순 마감 문구 · 미응답 리드 팔로업.

## 5. 측정(정직하게)
- 리드 1건 = 무료샘플 폼 제출 또는 직접 문의(메일/카톡/크몽). UTM으로 채널 귀속.
- 주차별 누적 대비 목표(5/13/21/30) 체크. 미달 채널은 다음 주 자원 재배분.

## 6. 대표 실행 필요(내가 못 하는 것)
- 인스타/당근 실제 게시 · 크몽 기그 수정 · 직접 DM/메일 발송 · 무료 샘플 실제 제작 · 광고 집행(선택) · GA4 측정ID.
- 나는 **자산·카피·랜딩·트래킹·리스트·템플릿**을 전부 준비해 대표가 "복붙 실행"만 하면 되게 만든다.

# 구글 노출 키트 — 인증 대본 + 리뷰 요청 (복붙 실행용)

> 목표: 구글 비즈니스 프로필 인증 통과 → "제주 영상제작" 지도 노출 → 리뷰로 순위 급상승.
> ※ 소개글(설명)은 이미 등록 완료.

---

## A. 영상 인증 대본 (30~60초 · 끊지 말고 한 번에 촬영)
> 세로/가로 아무거나. 폰 하나로 걸으면서 쭉 찍으세요. "실제로 이 사업을 운영한다"만 보여주면 됨.

**타임라인**
```
0~10초  장비: "안녕하세요, 제주 영상제작 스튜디오 비디오 로스터리입니다."
        → 카메라·드론·삼각대·노트북(편집 프로그램 열린 화면) 천천히 비추기
10~25초 신원+온라인: 노트북/폰으로 videoroastery.com 접속 화면 보여주기
        → 이어서 크몽 프로필(★4.5 후기) 화면도 슬쩍
25~40초 작업 증거: 편집 중인 프로젝트 타임라인, 납품한 영상 몇 개 재생
40~55초 공간/현장: 작업하는 책상·주변, (가능하면) 제주 촬영 현장 몇 초
55~60초 마무리: "제주에서 영상·홈페이지 만듭니다. 감사합니다." + 카메라 정면
```
**체크**
- ✅ 한 컷으로(편집·컷 전환 X — 편집하면 반려율↑)
- ✅ 얼굴 안 나와도 됨(손·장비·화면 위주 OK)
- ✅ 밝은 곳, 흔들림 최소
- ❌ 스톡영상·남의 화면 금지(감지되면 정지)

---

## B. 구글 리뷰 요청 템플릿 (작업했던 고객에게)
> 인증 승인 후, 만족한 고객에게. **리뷰 링크**는 프로필 → "리뷰 요청" 또는 "고객에게 요청"에서 복사(g.page/... 형태).

**카톡/문자 (짧게):**
```
사장님 안녕하세요, 비디오 로스터리입니다 :)
지난번 [영상/홈페이지] 작업 잘 쓰고 계신가요?
괜찮으셨다면 구글에 짧게 후기 한 줄 남겨주시면 정말 큰 힘이 됩니다 🙏
👉 [리뷰 링크]
1분이면 되고, 별점만 눌러주셔도 감사해요!
```

**메일 (조금 더 정중):**
```
제목: [고객사]님, 짧은 후기 한 줄 부탁드려요 🙏

안녕하세요, 비디오 로스터리입니다.
지난 [프로젝트] 함께해 주셔서 감사했습니다.

혹시 결과물이 만족스러우셨다면, 구글에 짧게 후기를 남겨주실 수 있을까요?
다른 제주 사장님들이 저희를 찾는 데 큰 도움이 됩니다.
👉 [리뷰 링크]  (1분, 별점만도 감사합니다)

앞으로도 필요하실 때 편하게 연락 주세요. 감사합니다!
```

**요령**
- 만족 표현한 고객에게만 (별점 낮을 사람에게 X)
- 작업 직후~1주 내가 응답률 최고
- 한 번에 몰지 말고 하루 2~3명씩 → 자연스러운 리뷰 유입
- 목표: 첫 달 **리뷰 5~10개** = "제주 영상제작" 로컬 순위 눈에 띄게 상승

---

## C. 인증 승인 후 프로필 마무리 (클릭률↑)
1. **사진 5~10장**: 로고 · 작업물 썸네일 · 장비 · 제주 촬영 현장 · (있으면)작업 공간
2. **영업시간**: 예약제면 "예약제" 또는 상담 가능 시간
3. **소셜 링크**: 인스타(@1minute_jeju)·유튜브·크몽 연결
4. **게시물**: 주 1회 최근 작업/무료샘플 오퍼 올리기(무료 노출)
5. **서비스 항목**: 홍보영상·드론·AI숏폼·홈페이지 등록

---
### 순서 요약
인증(영상) → 승인 대기(며칠) → 사진·시간 채우기 → 리뷰 요청 시작 → 게시물 주1회
= 몇 주 뒤 "제주 영상제작/홍보영상" 검색에서 지도+업체로 노출.

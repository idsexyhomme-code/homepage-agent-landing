# 10일 현금 파이프라인 — 플래시 오퍼 + 발송 메시지 (2026-07-26)

> 목표: 8/5 전 300만원. 레버=warm 접점(과거고객·문의·인스타·크몽). 콜드 금지.
> 총 6~8건 클로즈 목표. ⚠️ 가격 숫자는 대표 확정.

## 플래시 오퍼 (선착순·기한·명확)
**"촬영 없이, 사진만 보내면 3일 안에 릴스."** 이번 주 선착순 5팀.
| 티어 | 내용 | 가격(제안·조정) | 납품 |
|---|---|---|---|
| A · 릴스팩 | 릴스 3편 (사진 기반) | **20만원** | 3일 |
| B · 릴스+ | 릴스 5편 + 스토리컷 3 | **33만원** | 4일 |
| C · 큰 건 | 홈페이지 / 브랜드영상 / 매장 풀패키지 | **70만원~** (별도견적) | 1~2주 |
- 마진/속도: 사진 기반 + Higgsfield로 빠르게 → 하루 여러 팩 소화 가능.
- 클로징 촉진: "이번 주 5팀", "사진만 주시면 오늘 시작", 선입금 or 절반 선입금.

## 메시지 1 — 과거 고객 재접촉 (현금 최속) ★
```
사장님 안녕하세요, 비디오 로스터리입니다 😊 요즘 [브랜드/가게] 잘 지내시죠?
이번 주에 '촬영 없이 사진만으로 릴스 만들기'를 선착순으로 진행하는데,
예전에 함께 작업했던 분들께 먼저 연락드려요.
릴스 3편 3일 납품에 [20]만원이에요. 새 메뉴·신제품·알리고 싶은 거 있으면
사진 몇 장만 주시면 바로 만들어 드릴게요. 관심 있으시면 편하게 답 주세요!
```

## 메시지 2 — 로컬/인스타 featured 가게 (웜)
```
안녕하세요 사장님! '1분 제주'에서 [가게명] [본 것]로 소개해드렸던 비디오 로스터리예요 😊
이번 주 선착순으로, 촬영 없이 갖고 계신 사진으로 릴스 3편(3일 납품)을 [20]만원에 만들어드려요.
원본이나 예시 먼저 보여드릴 수 있으니, 관심 있으시면 사진 5장 정도만 주세요. 오늘 바로 시작 가능해요!
```

## 메시지 3 — 크몽 문의 즉시응대 템플릿
```
안녕하세요! 문의 감사합니다 😊 [요청내용] 건, 촬영 없이 보유 사진/자료로
[납품물]을 [기간] 안에 제작해 드립니다. 지금 진행 가능하고, 사진 몇 장만 주시면
바로 착수해요. 필요하시면 예시 컷 먼저 보여드릴게요!
```

## 실행 순서 (오늘)
1. 과거고객 리스트 → 메시지1 전 발송(가장 빠른 현금).
2. 크몽 gig 활성/노출 + 문의 10분 내 응답.
3. 인스타 featured 가게 → 메시지2 (하루 웜 다수).
4. 응답 오면 → 사진 받기 → Higgsfield로 즉시 제작 → 납품 → 입금.

## 세그먼트별 과거고객 재접촉 오프너 (포트폴리오 기반 — 명단 오면 즉시 매칭)
> 대표가 이름만 주면 [   ]만 채워 바로 발송. 톤=반갑게·짧게·구체 오퍼.

**A. 기업/브랜드 (감귤·농산물·ESG·공공·기업홍보 클라)**
```
[담당자님] 안녕하세요, 비디오 로스터리입니다 😊 [지난 프로젝트]는 잘 활용되고 계신가요?
이번 주에 촬영 없이 보유 자료로 숏폼·릴스를 빠르게 만들어드리는 걸 진행 중이라,
함께 작업했던 곳들께 먼저 연락드려요. 새 캠페인·신제품·연말 결산 콘텐츠 등
필요하시면 3~5일 안에 만들어 드릴 수 있어요. 편하게 회신 주세요!
```

**B. 카페/맛집/로컬 매장**
```
사장님 안녕하세요! 비디오 로스터리예요 😊 요즘 [가게] 바쁘시죠?
촬영 없이 갖고 계신 사진만으로 릴스 3편(3일 납품)을 이번 주 선착순 [20]만원에 만들어드려요.
신메뉴나 요즘 미는 거 있으면 사진 몇 장만 주세요. 오늘 바로 시작 가능해요!
```

**C. 웨딩/개인 고객**
```
안녕하세요 😊 비디오 로스터리입니다. [지난 촬영] 잘 간직하고 계신가요?
혹시 주변에 웨딩·기념일 영상이나, 가게 하시는 분 중 홍보 영상 필요한 분 계시면
소개해 주시면 정성껏 만들어 드릴게요. 이번 주 선착순 진행 중이에요!
```
(→ 웨딩 고객은 재구매보다 **소개(referral)** 요청이 현실적)

**D. 홈페이지/앱 클라**
```
[대표님] 안녕하세요, 비디오 로스터리입니다 😊 [사이트/앱]은 잘 운영되고 계세요?
지금 촬영 없이 제품·서비스 소개 영상(숏폼)을 빠르게 제작해드리는 걸 진행 중이에요.
랜딩/광고에 바로 쓸 수 있는 컷 필요하시면 며칠 안에 만들어 드릴게요. 편하게 연락 주세요!
```

## 발송 원칙 (스팸 방지·응답률↑)
- 하루 한 사람에게 1회. 개인화 1문장 필수(지난 작업·가게 특징).
- "선착순·이번 주·3일 납품" = 지금 답할 이유. 가격은 명확히.
- 답 오면 10분 내 재응답 → 사진 요청 → 즉시 착수.

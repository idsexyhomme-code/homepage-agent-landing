# 당근 광고 "제안 오게" 개선 키트 — 초안 (대표 검토·수정 후 사용)

## 진단 — 지금 광고가 제안을 못 만드는 이유
현재 광고: "홈페이지부터 문의자동화 SNS홍보까지 / 한 견적으로 묶어드려요 / 무료 상담으로 범위 정하기"
- **너무 많고 뭉뚱그려짐** → "나한테 뭐가 필요한지" 안 꽂힘. "세트로 다 묶어"는 커 보이고 비싸 보여 **문턱↑**.
- **"무료 상담" = 영업전화 부담.** 당근은 "부담 0의 구체적 한 가지"에 반응.
- **기능 나열**(홈페이지·문의·영상·카드뉴스·인스타·유튜브) → 성과가 아님([[copy-voice-principle]] 위반).
- **제주·실사례·★4.5 로컬/신뢰 신호 없음.**

## 🔑 먼저 확인할 딱 하나 (수리 방향 결정)
- **클릭은 오는데 문의가 없다** → 광고는 OK, **도착지·오퍼** 문제 → 아래 오퍼/랜딩 개선.
- **클릭 자체가 적다** → **크리에이티브·타깃** 문제 → 아래 카피/크리에이티브 개선.
- 당근 광고관리에서 **노출·클릭·클릭률**만 보면 어느 쪽인지 압니다. (알려주시면 그쪽부터 집중)

## 광고 카피 3안 (성과 우선 · 저마찰 오퍼 · 당근 톤)
> 원칙: 광고 하나 = 서비스 하나 = 오퍼 하나. 여러 개를 A/B로 돌리고 이기는 걸 남기세요.

### A안 — 홈페이지 1개에 집중 (가장 명확, 추천)
- 배지: `제주 동네 사장님`
- 헤드라인: **검색해서 찾아온 손님이, 딴 데 안 가게**
- 바디: 첫 화면에서 "여기 믿을 만하다"가 느껴지는 우리 가게 홈페이지. 사진만 주시면 시작합니다.
- CTA: **무료로 첫 화면 시안 받아보기**
- 도착지: `videoroastery.com/homepage/?utm_source=danggeun&utm_medium=cpc&utm_campaign=home_A`

### B안 — 무료 진단 (문턱 0, 제안 유도에 최강)
- 배지: `무료 진단`
- 헤드라인: **지금 쓰는 홈페이지·인스타, 손님 눈엔 어떻게 보일까요?**
- 바디: 제주 사장님 가게 온라인 첫인상 — 좋은 점 1, 아쉬운 점 1, 바꾸면 좋을 것 1. 무료로 봐드려요.
- CTA: **무료 진단 받기 (사진 1장이면 끝)**
- 도착지: 카톡 오픈채팅 또는 `/estimate/?utm_source=danggeun&utm_campaign=diagnosis_B`

### C안 — AI 숏폼/영상 (촬영 없이, 제품 사장님)
- 배지: `촬영 0원`
- 헤드라인: **제품 사진 몇 장이면, 광고 영상이 됩니다**
- 바디: 촬영·모델·스튜디오 없이 릴스·쇼츠 광고. 재구매 고객이 증명한 결과예요.
- CTA: **내 제품으로 어떤 영상 나올지 보기**
- 도착지: `videoroastery.com/ai-shortform/?utm_source=danggeun&utm_campaign=shortform_C`

## 오퍼 재설계 — "무료 상담" ✕ → 구체적 저마찰 ✓
- "무료 첫 화면 시안 1장" / "무료 진단 1장" — **받는 게 명확**해야 신청함.
- "사진만 주세요" — 준비물 최소 = 문턱 최소.
- "크몽 24건+ 완료·재구매" — 사실 기반 신뢰 (당근 사장님은 이웃 신뢰에 반응).

## 크리에이티브 방향 (지금 이미지 → 이렇게)
- **텍스트·박스 줄이기.** 지금은 다이어그램이 커서 복잡해 보임 → 다이어그램은 2번째 슬라이드/상세로.
- **첫 슬라이드 = 실제 대표 제작물 1개 크게 + 헤드라인 1줄 + 오퍼 1줄.** (사람 얼굴·현장·실물 = 당근 신뢰)
- **제주 로컬 명시** ("제주 사장님", 동네 느낌).

## 도착지 + 추적 (중요)
- 광고마다 **UTM** 붙여 링크 → 문의폼 제출 시 **메일에 어느 광고에서 왔는지 자동 기록**(사이트에 이미 구현됨). 어떤 광고가 제안을 만드는지 바로 보입니다.
- **홈(영상월)보다 서비스 페이지·견적폼으로** 보내는 게 콜드 트래픽 전환에 유리 (영상월은 멋지지만 "나도 문의 가능"이 덜 명확).

## 당근 비즈프로필 + 소식 (광고 신뢰 보강 — 광고만으론 약함)
- **프로필 소개**: "제주에서 영상·홈페이지 만드는 비디오 로스터리. 실제 작업물로 상담하고, 고정가 없이 딱 맞는 견적. 크몽 24건+ 완료·재구매." + 단골 맺기 유도.
- **소식 게시글 3개(드래프트)**:
  1. 실제 제작 사례 before/after 1건 (사진 + "이렇게 바뀌었어요")
  2. "무료로 우리 가게 온라인 첫인상 봐드려요" 안내
  3. 제주 사장님 팁 1개 ("홈페이지 맡기기 전 확인할 것" 등 — naver-blog-drafts.md 재활용)

## 1. 네이버 스마트플레이스 등록 키트

네이버 검색·지도에서 "제주 영상제작" 등으로 노출되는 가장 중요한 채널입니다. 무료이고, 제주 소상공인 고객이 가장 먼저 찾는 곳이라 1순위로 하세요.

### 1-1. 등록 절차 (순서대로)

1. **네이버 비즈니스 접속**: `smartplace.naver.com` → 네이버 아이디로 로그인 (사업자 아이디 권장).
2. **[신규 등록]** 클릭 → 업종을 "미용·건강·기타 서비스" 계열이 아니라 **"기타 서비스업 > 영상·사진"** 쪽으로 검색해서 선택 (정확한 카테고리는 1-4 참고).
3. **업체 기본정보 입력**: 상호(비디오 로스터리), 전화(대표 연락처), 주소.
   - 매장이 없는 출장/온라인 위주라면 **"방문 없이 서비스 제공"** 또는 사업장 주소를 넣고 "지도 비노출" 옵션을 선택할 수 있습니다. 실제 작업 공간 주소가 있으면 그걸 넣는 게 신뢰에 유리합니다.
4. **사업자등록 확인**: 사업자등록번호 입력 → 자동 인증. (개인/간이과세자도 등록 가능)
5. **업체 소개글 입력**: 아래 1-2의 텍스트를 붙여넣기.
6. **대표 키워드/찾아오는 길/영업시간 입력**: 1-5 키워드 붙여넣기.
7. **사진·영상 등록**: 대표 이미지 1장(로고 또는 대표작 썸네일) + 포트폴리오 스틸컷 5~10장 + **유튜브 영상 링크 첨부**(스마트플레이스는 동영상 URL 등록 지원).
8. **저장 → 심사 제출**. 보통 1~3영업일 내 노출.
9. **노출 후**: 소식(1-6)을 바로 3개 올려 "살아있는 업체" 신호를 줍니다.

> 팁: 등록 직후 지인/기존 고객에게 **네이버 방문/블로그 리뷰**를 부탁하세요. 크몽 후기는 네이버에 안 보이므로, 네이버 자체 리뷰가 초기 순위에 큰 영향을 줍니다.

## 3. 글로벌 크리에이티브 플랫폼 (Vimeo + Behance)

```

We help brands look the way they deserve — on location across Jeju and online worldwide. See the full portfolio and get a custom quote at videoroastery.com.
```

**백링크 넣는 위치 (3곳 모두)**
1. 프로필 **Website/URL 필드** → `https://videoroastery.com`
2. 프로필 **Bio 본문 마지막 줄** (위 문구에 이미 포함)
3. **각 영상 Description 하단** → 아래 템플릿의 마지막 줄

**어떤 영상을 올릴까 — 48편 중 대표작 선정 가이드 (카테고리별 1~2편, 총 8~12편)**
> Vimeo는 "적지만 최고"가 원칙입니다. 48편 전부 올리지 말고, 카테고리별 최고작만 선별하세요.
- **브랜드 필름 / 기업 홍보** — 가장 완성도 높고 스토리가 있는 것 2편
- **드론 / 항공** — 제주 풍경이 압도적인 것 1~2편 (해외 시청자에게 가장 잘 먹힘)
- **AI 숏폼 광고** — "촬영 없이 이게 된다"가 놀라운 것 1~2편

각 항목은 **대표님이 30분~1시간이면 끝낼 단위**로 쪼갰습니다. 위에서부터 순서대로. 완료하면 `[x]` 표시.

### 1주차 — "검색에서 발견되게" (로컬 필수 3종)
- [ ] **(1시간)** 네이버 스마트플레이스 등록 — 섹션 1 절차대로. 소개글·키워드·카테고리 붙여넣기, 유튜브 영상 링크 첨부. **← 최우선**
- [ ] **(30분)** 스마트플레이스 첫 소식글 3개 게시 (1-6 그대로).
- [ ] **(45분)** 구글 비즈니스 프로필 등록 — 섹션 2. 인증 요청까지 걸어두기(승인은 며칠 걸림).
- [ ] **(15분)** 기존/지인 고객 2~3명에게 네이버 방문 리뷰 부탁 문자.

### 2주차 — "이미 있는 자산 강화" (크몽 + 구글 마무리)
- [ ] **(1시간)** 크몽 프로필 최적화 — 서비스 5종 분리 등록, 썸네일 톤 통일, 소개에 포트폴리오 맥락으로 홈페이지 언급.
- [ ] **(30분)** 완료 고객에게 크몽 후기 요청 (★ 늘리기).
- [ ] **(30분)** 구글 비즈니스 인증 완료 처리 + 첫 게시물(2-5) 등록 + 사진 10장 업로드.
- [ ] **(15분)** 유튜브 채널 설명란·배너에 videoroastery.com 링크 점검(없으면 추가).

### 3주차 — "프로처럼 보이게" (글로벌 포트폴리오)
- [ ] **(1시간)** Vimeo 계정 개설 + Bio(3-1) + 대표 영상 8~12편 선별 업로드 + 설명 템플릿 적용 + 백링크 3곳.
- [ ] **(1시간)** Behance 프로필(3-2) 개설 + 웹/영상 케이스 3~5개 등록 + 백링크.
- [ ] **(30분)** Clutch.co 무료 등록 + 고객 1명에게 Clutch 리뷰 요청.
- [ ] **(20분)** DesignRush 무료 등록.

### 4주차 — "알려지게 + 지역 인프라" (PR + 제주 지원)
- [ ] **(45분)** PR 피치 발송 — 앵글①(AI 숏폼)을 테크/스타트업 매체 2곳 + 지역지 1곳에 개별 발송.
- [ ] **(30분)** PR 피치 앵글②(로컬 크리에이터) 지역 매거진/제주의소리 1~2곳 발송.
- [ ] **(30분)** 제주창조경제혁신센터(jccei.kr) 지원사업 공고 확인 + 로컬크리에이터/콘텐츠 사업 1건 신청 또는 문의.
- [ ] **(20분)** 제주 소상공인 온라인 진출 지원사업(수행기관/공급기업 모집) 공고 검색 + 등록 문의 메일.
- [ ] **(15분)** Crunchbase 회사 프로필 등록(무료 백링크).

### 이후 매주 반복 (유지·관리, 주 20분)
- [ ] 스마트플레이스 소식글 주 1개 (신규 작업물 소개).
- [ ] 신규 완료 고객마다 네이버·크몽·구글 리뷰 1건씩 요청.
- [ ] PR 무응답 매체 1회 리마인드 / 신규 매체 1곳 추가 피치.
- [ ] Vimeo·Behance 신작 1편 추가.

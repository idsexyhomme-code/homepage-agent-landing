# 검색광고 셋팅 키트 — "AI 영상제작" (2026-09-07)

대표 요청: "우리 홈페이지 검색광고 셋팅해놔야 해, AI 영상제작으로 특히나."
사이트 쪽(착지 페이지·전환 추적·유입 귀속)은 **전부 구현·배포 완료**. 계정 쪽(로그인·충전·ID 발급)은 대표만 할 수 있어 아래 체크리스트로 남김.

| 전환 추적 훅 | `app.js` `AD_TRACKING` — 네이버 프리미엄 로그분석 `wa` / Google Ads `AW-…`+라벨을 넣으면 공통 스크립트 자동 주입 + **문의 폼 전송 성공 시 전환 1건 자동 보고**(네이버 전환유형 4 "신청/예약", 구글 conversion 이벤트). 지금은 빈 값 → 아무것도 로드 안 함 |

## 대표가 해줄 것 (순서대로)
1. **네이버 검색광고 가입/로그인** → https://searchad.naver.com (사업자: 주식회사 보구정 정보로)
2. 광고시스템 → **도구 → 프리미엄 로그 분석 신청** → 공통 스크립트의 `wcs_add["wa"]="s_…"` 값을 나에게 → 내가 `AD_TRACKING.naverWa`에 넣고 배포
3. 도구 → **자동 추적 URL 파라미터 "사용"** 체크
4. **비즈채널(웹사이트) 등록** `https://videoroastery.com` → 검수. 검수에서 "사이트에 사업자 정보 표기" 요구가 오면 → **상호·대표자·사업자등록번호·주소·연락처**를 나에게 주면 푸터에 넣어 배포 (지금 사이트엔 사업자 정보가 어디에도 없음)
5. **비즈머니 충전** (내가 결제 못 함) — 첫 달 30만원 권장
6. (선택) **Google Ads** 계정 생성 → 전환 액션 만들어 `AW-ID`+라벨 전달. 네이버 2주 돌린 뒤 시작 권장
7. 여기까지 되면 **내가 대표 브라우저(맥북에어 크롬)에서 캠페인·그룹·키워드·소재·확장소재·제외키워드를 전부 입력**하고 **"노출 시작" 직전에 멈춤** → 대표가 확인하고 켬

## 키워드 조사 결론 (네이버 월간 검색량, 2026-09-07 실측)
- **`AI 영상제작` 4,100** (PC 2,190 / 모바일 1,910) — 큰 키워드지만 연관검색어가 무료·사이트·프로그램·툴·방법·강의·프롬프트·추천 순 → **대부분 직접 만들려는 사람**. 그래서 이 키워드는 저가 상한(900원)으로 하단 노출만.

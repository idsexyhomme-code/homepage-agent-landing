# Google Ads (검색) — 캠페인 설계서
작성 2026-09-07 · 착지 `/ai-video/` · 계정: ads.google.com (대표 Google 계정으로 생성/로그인 필요)
## 0. 계정에서 먼저 (1회)
1. Google Ads 계정 생성 시 **'전문가 모드'** 로 전환(스마트 캠페인 금지 — 키워드 통제 불가).
2. **목표 → 전환 → 새 전환 액션 → 웹사이트 → 수동 설정**: 이름 `문의 제출(inquiry_sent)`, 카테고리 `리드 제출`, 값 없음, 집계 `1회`. 발급된 **전환 ID(`AW-xxxxxxxxx`)와 라벨**을 나에게 전달 → `AD_TRACKING.googleAw / googleLabel` 넣고 배포. (gtag 기본 코드도 같이 심어짐)
3. 결제 정보 등록 — 대표 직접. 자동 태깅(gclid) 기본 ON 유지.

## 2. 광고그룹 · 키워드
네이버와 같은 6그룹. **구문 일치(" ")** 기본, 광역 그룹·브랜드는 **완전 일치([ ])**. 파일 그대로 Google Ads Editor에 가져오기(**Paused 상태로 들어감** — 대표 확인 후 Enable):
- `google-ads-editor-keywords.csv` (키워드·매치·CPC·URL)
- `google-ads-editor-negatives.csv` (캠페인 제외 키워드, 구문 일치)
- `google-ads-editor-rsa.csv` (반응형 검색광고 — 그룹당 1개, 제목 15·설명 4)

Editor 없이 웹에서 할 때: 광고그룹 만들기 → 키워드 칸에 `naver-keywords-paste.txt`의 블록을 붙여넣되 각 줄을 `"키워드"`(구문) 형태로.

# 네이버 검색광고(파워링크) — 캠페인 설계서
작성 2026-09-07 · 착지 페이지 `/ai-video/` · 계정: searchad.naver.com **개인 광고주**(보구정 법인 사용 금지 — 대표 지시) · 이 도메인은 내 브라우저 도구가 차단해 **입력은 대표가 직접**
## 0. 계정에서 먼저 켜둘 것 (1회)
1. **광고시스템 → 도구 → 프리미엄 로그 분석** 신청 → 발급된 공통 스크립트에서 `wcs_add["wa"]="…"` 값을 나에게 전달 → 사이트 `AD_TRACKING.naverWa`에 넣고 배포(전환 추적 시작).
2. **도구 → 자동 추적 URL 파라미터: 사용** — 클릭 URL 뒤에 `n_media·n_query·n_keyword·n_ad_group·n_ad` 가 자동으로 붙고, 사이트가 이 값을 문의 메일에 실어 보냄(어떤 키워드가 문의를 만들었는지 확인 가능).
3. **비즈채널 등록**: 웹사이트 `https://videoroastery.com` (검수 1~2영업일). 개인 광고주는 가입자(서형민)와 사이트 운영자가 같아야 함 → 사이트 회사소개/푸터의 대표 이름과 일치. ⚠️ 영리 사이트라 검수에서 "사업자등록 필요"로 반려될 가능성 있음 → 그 경우 **개인사업자 등록(홈택스 온라인·무료·당일~2일)** 후 계정을 사업자로 전환하는 게 답(보구정 법인은 쓰지 않음).
4. **비즈머니 충전** — 대표가 직접(결제는 내가 못 함). 첫 달 권장 **30만원**(일예산 1만원 × 30일; 아래 예산 참고).

키워드 전체 목록·검색량·입찰상한: **`keywords.csv`** / 그룹별 붙여넣기 블록: **`naver-keywords-paste.txt`**

**입찰 원칙**
- 네이버 **키워드 도구**(광고시스템 → 도구)에서 각 키워드의 "순위별 예상 입찰가"를 보고, **3~5위 노출가**로 시작. 위 상한을 넘기면 그 키워드는 상한에서 멈춤.
- 검색량 큰 광역 키워드(`AI 영상제작` 4,100)는 무료 툴·강의 검색자가 대부분 → **절대 1~2위 입찰 금지**. 저가로 하단 노출만.
- 2주 후: 클릭 20+ 인데 문의 0인 키워드는 입찰 -30% 또는 OFF. 문의 만든 키워드는 +20%.
## 3. 제외 키워드 (`negative-keywords.txt`, 검색어 확장 ON 그룹 전부에 등록)
무료·사이트·프로그램·툴·앱·방법·만들기·강의·교육·프롬프트·채용·유튜버·다운로드 + 생성툴 이름(소라·런웨이·클링·미드저니·브루·캡컷·챗GPT 등). **`추천·비교·후기·저렴`은 제외하지 않음** — "AI 영상제작 업체 추천"은 구매 의도.

## 6. 전환 추적 확인법
1. 프리미엄 로그분석 켜진 뒤 `/ai-video/` 폼을 실제로 1건 제출(테스트 문의라고 적기) → 광고시스템 **보고서 → 전환 지표**에 "신청/예약(4)" 1건 잡히면 정상.
2. 문의 메일 본문 맨 아래 `유입: utm_source=naver · n_keyword=…` 줄이 붙어 오면 키워드 귀속도 정상.

## 7. 운영 루틴 (주 1회 10분)
- 보고서 → 광고그룹별 **클릭·비용·전환** 확인. 문의 1건당 비용(CPA) 5만원 이하면 예산 증액.
- **검색어 보고서**에서 DIY성 검색어(무료·사이트·툴…) 새로 보이면 제외 키워드에 추가.
- 소재 CTR 1% 미만이면 제목 교체(대체 문구 위 참고).

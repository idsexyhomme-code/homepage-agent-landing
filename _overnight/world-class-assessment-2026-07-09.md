# 세계적 수준(한국관광공사급) 진단 · 로드맵 — 2026-07-09

> 대표 지시: "한국관광공사급 세계적인 홈페이지가 되게, 고민해주고 밤새 작업 이어가줘."
> 방법: 감으로 기능 추가하지 않고, **라이브 실측(성능·접근성·기술) 후 격차를 정직하게 진단**하고 우선순위화.

## 결론 먼저 (정직하게)
**videoroastery.com은 이미 "측정 가능한 기술 지표"에서 세계적 수준이다.** 실측 근거:
- **성능 펀더멘털**: TTFB 188ms, DOM 654노드(가벼움), 리소스 35개, **외부 요청 0**(완전 셀프호스트 — 광고/트래커/외부폰트 없음. 웬만한 대형 사이트보다 깨끗). app.js 42KB·style.css 19KB.
- **접근성(A11y)**: h1 1개·제목 위계 논리적, **alt 누락 0**(장식 이미지 빈 alt 정확), 링크/버튼 접근명 100%, 랜드마크 완비, `:focus-visible` 존재, 양수 tabindex 0. → WCAG AA 사실상 충족.
- **SEO/구조화데이터**: Organization·Service·FAQPage·VideoObject·BreadcrumbList·WebPage, hreflang(HTML+sitemap) 4개국, sitemap 16 URL, 보안헤더 5종, 브랜드 404. → 매우 완비.
- **다국어**: 한/영/简/繁 4개국, 언어전환.

**즉, KTO급과의 진짜 격차는 "기술"이 아니라 "경험·에디토리얼·콘텐츠 깊이"다.** 이건 대부분 브랜드 큐레이션 결정이라 대표 방향이 필요(자율로 갈아엎으면 대표가 손수 큐레이션한 톤을 해칠 위험 — 과거 히어로/골드색 교훈).

## KTO급으로 가는 로드맵 (임팩트 × 난이도 × 리스크)

### A. 안전·자율 가능 (기술/폴리시 — 내가 밤새 진행 가능)
1. **LCP 최적화**: 히어로 영상월 첫 타일 preload + 재생 우선순위 조정으로 체감 로딩 개선(현재 load ~2s). 안전.
2. **이미지 blur-up/페이드인**: 로드 시 부드러운 등장(프리미엄 감). scroll-reveal과 톤 통일. 중난이도·저risk.
3. **모션 일관성 패스**: hover/transition 타이밍·이징 통일, 카드 hover 미세 확대 등 절제된 마이크로 인터랙션.
4. **프린트 스타일시트 / OG 이미지 페이지별 정교화** 등 마감.

### B. 경험·디자인 (대표 방향 필요 — 브랜드 큐레이션)
1. **몰입형 스토리텔링 히어로**: KTO처럼 스크롤에 반응하는 풀블리드 영상/카피 시퀀스. (현재 마퀴 영상월 → 더 에디토리얼하게)
2. **케이스 스터디 심화**: 각 대표작에 "문제→제작→결과(수치)" 스토리 페이지. KTO의 여행기사 같은 깊이.
3. **섹션 리듬·여백 재설계**: 대형 타이포·풀블리드 이미지·넉넉한 여백의 에디토리얼 레이아웃.

### C. 콘텐츠·신뢰 (대표 입력/자산 필요)
1. **실제 성과 수치**(조회수·전환·리드 증가 등)로 신뢰자산화 — 크몽 후기 외.
2. **영문/중문 카피 원어민 검토**(글로벌 신뢰도).
3. **GA4·네이버플레이스·구글비즈**(측정·로컬 노출) — 이미 대기 목록.

## KTO(imagineyourkorea)가 잘하는 것 = VR이 벤치마크할 것
- 풀블리드 영상 + 절제된 대형 타이포 + 넉넉한 여백(에디토리얼).
- 강한 시각 위계(한 화면 = 한 메시지).
- 스크롤에 반응하는 자연스러운 모션(과하지 않게).
- 다국어·접근성·성능을 기본으로 깔고 **콘텐츠(스토리)로 승부**.

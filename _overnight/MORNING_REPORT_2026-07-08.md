# 아침 보고서 — 2026-07-08 밤샘 빌드업 (vr 세션)

> 대표 지시: "외국어 3페이지 상단 아이콘→홈, 밤새도록 세계적으로 더 빌드업, 멈추지 말고."
> 원칙: **배포마다 Codex GO/NO-GO 게이트**(대표 확정 정책). 주관적 카피 재작성·대외 브랜드 결정은 자율 배포 금지 → 스테이징·플랜으로.

## ✅ 오늘 밤 라이브 배포된 것 (전부 Codex GO + 라이브 검증 완료)

### 배치 0 — 외국어 상단 아이콘 → 홈 + 번체 교정
- **en/zh/zh-hant 브랜드 로고(헤더·푸터 4곳)** 클릭 → 자기 페이지가 아니라 **한국어 메인 홈(/)**으로. (사이트 공통 규칙과 일치. 언어전환 스위처는 안 건드림)
- **번체(繁) 카피 교정**: `無人機航拍`(대륙식) → `無人機空拍`(대만식). 간체 `无人机航拍`은 대륙식이 맞아 보존.

### 배치 1 — Codex 심층 재검증 후속 버그 2건 수정 (초저녁)
- **High**: 생성기 `main()`이 루트 index.html까지 덮어쓰던 함정 → 루트 스킵 가드 추가.
- **Low**: en/zh/zh-hant JSON-LD `WebSite.inLanguage:"ko-KR"` 언어 불일치 → 제거(WebPage는 언어별 정확 유지).

### 배치 A — sitemap 다국어(hreflang) 강화
- sitemap.xml의 홈·/en/·/zh/·/zh-hant/ 4개 URL에 **hreflang alternate 5종(ko/en/zh-Hans/zh-Hant/x-default)** 상호 명시. 생성기 `write_sitemap()`도 동기화(회귀 방지).

### 배치 B — 보안 헤더 하드닝
- vercel.json에 **Referrer-Policy·Permissions-Policy·X-Frame-Options** 추가. 라이브 확인: 5종(+기존 HSTS·nosniff) 응답.
- ⚠️ **CSP는 일부러 제외**(인라인 스크립트·외부 폰트 CDN 깨질 위험) → 아침 논의감.

### 배치 C — 브랜드 404 페이지 (배포·라이브 검증 완료)
- 신규 `404.html`: 다크+골드 브랜드 톤, "페이지를 찾을 수 없습니다"+EN/中, 홈·문의·4개국어 링크, noindex. 자체완결(외부 의존 0).
- 라이브 검증: 미존재 경로 → 308(트레일링슬래시) → 최종 404 + 브랜드 페이지 서빙 확인.

### 🔒 보너스: 내부 문서 누출 차단
- 배포 직전 Codex가 잡음: `REMEMORY_HANDOFF.md`(내부 핸드오프)가 배포에 섞일 뻔 → `.vercelignore` 추가로 차단. 라이브 노출 0(404 유지) 확인.

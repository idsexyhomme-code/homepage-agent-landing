# 홈페이지 파이프라인 + 구글검색 연결 (Phase 5 산출물)

> 목표: videoroastery.com을 **허브**로, 피버·크몽 gig을 **이행/사회적증거 레일**로 묶어
> "어디서도 파이프라인 안 생김"을 깬다. 구글 오가닉 → 오운드 랜딩 → (자가주문 gig OR 직접리드).

---

## 5-A. 파이프라인 구조 (허브-앤-스포크)
```
구글검색/유튜브/인스타 ─┐
                      ▼
        [videoroastery.com/market-report]  ← 오운드 허브(구글 랭킹은 여기서만 가능)
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
  "Fiverr에서 주문"  "크몽에서 주문"   "직접 문의(맞춤·고액)"
   (영어/글로벌)      (한국어/국내)      Web3Forms 폼(기존 재사용)
        │             │             │
        ▼             ▼             ▼
   피버 gig A/B     크몽 리포트 gig   대표 직접견적(맞춤 리서치 $$$)
```
- **왜 허브가 필요한가**: 피버/크몽 gig 페이지는 구글에서 잘 안 뜬다(플랫폼 내부검색용). **우리 도메인만 구글 오가닉을 먹는다.** 랜딩이 구글 트래픽을 잡아 gig으로 흘려보냄 = 대표가 못 만들던 "유입→전환" 다리.
- **양방향 링크 루프**: 랜딩→gig(전환) + gig→랜딩("see our studio", 신뢰·백링크). 이 루프가 파이프라인.

## 5-B. 신규 랜딩 스펙 (사이트 기존 패턴 그대로)
- 라우트: `/market-report/`(한국어) + `/en/market-report/`(영어). app.js 패턴 = enLandingPages/industryPages처럼 맵+렌더함수+render() 분기(pageTitle/Desc/Url/html)+정적셸 index.html(JSON-LD)+sitemap+predeploy_check.
- ⚠️ **지난 세션 데블스결론("thin 페이지 그만·측정먼저")과 정합**: 이건 thin 도어웨이가 아니라 **매출 상품페이지(고유 오퍼+리드캡처+실제 수익경로)** → 예외 정당. 단 **언어당 1페이지만**(플릿 금지).
- 섹션: 히어로(상품 한줄+CTA 2개) → 받는 것(리포트 구성) → **🎬 90초 비디오요약 샘플 임베드**(우리 웨지, 실제 렌더) → 샘플 리포트 프리뷰(PDF 이미지) → 3티어 가격표(gig 미러) → FAQ(gig 재사용) → CTA밴드(Fiverr/크몽/직접문의).
- CTA 3버튼: `Order on Fiverr ↗`(en 랜딩 주력) / `크몽에서 주문 ↗`(ko 랜딩 주력) / `맞춤 견적 문의`(#contact, 기존 quoteForm).
- JSON-LD: Service + Offer(가격) + FAQPage + BreadcrumbList (사이트 스키마 패턴 일치).

## 5-C. 구글검색 키워드 타겟 (랜딩이 노릴 것)
- 한국어(크몽 유도): `AI 시장조사 리포트`, `경쟁사 분석 리포트 제작`, `사업계획서 시장조사 대행`, `창업 시장조사`, `해외 시장조사 대행`.
- 영어(피버 유도): `Korea market entry research`, `Asia market research report`, `AI market research report`, `competitor analysis report service`.
- 앵글: **"Korea/Asia 진출 리서치"는 경쟁 적고 우리 해자** → 영문 랜딩 주력 키워드로. 브랜드검색("비디오 로스터리")과 별개 신규 오가닉.
- 사이트맵 추가 + Search Console URL 색인요청(기존 도메인속성 활용). 내부링크: 홈 #services·about에서 market-report로.

## 5-D. 측정 (자기기만 방지 — 기존 계측 확장)
- 랜딩 CTA에 이벤트: `report_cta_fiverr` / `report_cta_kmong` / `report_inquiry`(Clarity + Vercel 가상페이지뷰 `/market-report/sent` 패턴 재사용).
- **아웃바운드 클릭 추적**: Fiverr/크몽 링크 클릭 수 = "허브가 실제로 gig에 트래픽 흘리나" 검증. 안 잡히면 파이프라인 반증.
- gig→랜딩 유입은 Vercel Analytics referrer(fiverr.com/kmong.com)로 확인.

## 5-E. 위시캣·숨고 트랙 (리포트 아님 — 영상/홈페이지 프로젝트 리드)
- 위시캣: 대표가 **파트너 계정**으로 IT/영상/홈페이지 프로젝트에 지원(입찰). 리포트 gig 아님. 사이트 포트폴리오를 제안서에 첨부.
- 숨고: 로컬 제주 영상 카테고리에서 견적 발송(크레딧 소모 주의 — ROI 검증 전 소액 테스트만).
- 이 트랙은 사이트 기존 영상/홈페이지 서비스가 이미 대응 → 신규 개발 불필요, 채널 등록·운영만.

## 5-F. 시퀀싱 (죽은 링크 방지 — 중요)
1. **먼저**: 대표가 FIVERR_GIG_KIT로 피버 gig A + 크몽 리포트 gig **실제 생성 → URL 확보.**
2. **그 다음**: 그 실제 URL로 `/market-report` 랜딩 빌드(내가 코드 작성 가능, gig URL 받으면 즉시).
3. **동시에**: 샘플 리포트 1부 + 90초 비디오요약 1편 실제 제작(갤러리·랜딩·gig 공용 자산). ← 이게 전체의 병목 자산.
4. 측정 배선 → 배포 → Search Console 색인요청 → 오가닉/전환 관찰.

## 5-G. 데블스 애드버킷 (Phase 5)
- ⚠️ **피버 ToS**: 사이트→피버(트래픽 유입)는 OK. 피버가 데려온 바이어를 직접거래로 빼돌리면 ToS 위반. → "직접 문의" CTA는 *오가닉/사이트 자체 트래픽*에만, 피버 인입 바이어엔 금지.
- ⚠️ **랜딩 빌드는 gig URL 확보 후**(죽은 링크 방지). 지금 코딩 금지 = 옳은 절제.
- ⚠️ **진짜 병목은 페이지가 아니라 "샘플 리포트+비디오요약 1세트"** — 이 증거자산 없이는 gig도 랜딩도 콜드. 대표 실제 제작이 크리티컬패스.
- ⚠️ 측정 없이 페이지만 늘리면 지난 실패 반복 → 5-D 계측 필수 선행.

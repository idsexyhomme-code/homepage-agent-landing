Classes

One-on-One · Small-Group Practical Classes

3D modeling (Blender) · media art photography

2 hours per session · 3-session courses and others (on-site / online)

Brief

Each learner came with different tools and goals, so a general lecture was hard to apply to real work right away.

What we did

Chose one output and built the curriculum backwards from it, learning by making — a building modeled to dimensions, a three-shot exhibition mission.

Output

Class slides and script · shortcut memory cards · shooting and retouching cheat sheet · one-page checklist

3D modeling — Blender

For a practitioner coming from another 3D program, the class was built around modeling a two-story building on a 20 × 15 m site to exact dimensions, learning the interface, shortcuts and numeric input along the way. A mapping table between the previous program's functions and Blender's made it possible to move over from familiar habits, and each session came with a shortcut script and mobile memory cards.

Media art photography

For 8 staff members of a company that runs media art exhibitions, we organized five standards for photographing glowing screens in a dark hall, basic camera settings, shutter and flicker, and starting values by scene, and linked them to an on-site mission (three media art shots). A shooting and retouching cheat sheet and a one-page checklist were provided.

Class format

The first session confirms level and goals, one output is chosen, and the curriculum is built backwards from it. After each session, review materials for practicing alone are provided along with the assignment for next time.

Deliverables

  • Class slides · script
  • Shortcut · memory cards
  • Shooting · retouching cheat sheet
  • One-page checklist · practice mission

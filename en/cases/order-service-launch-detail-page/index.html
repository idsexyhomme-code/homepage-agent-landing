Launch Content for an Order Sorting Service

Sanjiro · Automatic parcel order sorting service · crowdfunding · B2B

October 2026

Brief

The service had many features, but a feature list alone did not convey how the user's work gets lighter.

What we did

Recorded manual entry and the service side by side for comparison, and explained each feature as "a day that changes" in each customer group's own words.

Output

Crowdfunding detail page in 15 sections · recorded real-use comparison page · 11-page adoption proposal for parcel agencies

Problem

The service had many features, but a feature list alone did not convey how the user's own work gets lighter.

Customer analysis

Collected the actual wording of three customer groups — farm owners, Dongdaemun wholesale buyers and parcel agencies — to organize their pain points, and set a structure that translates each feature into "how my day changes".

Proof design

Recorded the same five-line list being typed by hand and being sorted by the service, and built a comparison page. The three-step flow of paste → check → download Excel, real screens, on-site usage records, the shipping flow through to waybill printing and frequently asked questions were laid out as a vertical detail page. All names and numbers on screen are fictional sample data.

B2B proposal

Wrote a separate adoption proposal for parcel agencies in the order of current state → proposal → feature details → accuracy and privacy protection → rollout schedule.

Operations

The detail page was delivered as an editable design file so changes before the funding opens can be made right away.

Deliverables

  • Crowdfunding detail page (15 sections, PNG · PDF)
  • Recorded real-use comparison page
  • Adoption proposal for parcel agencies (11-page PDF)
